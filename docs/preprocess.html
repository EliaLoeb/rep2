UFC Tabel en Code

Onderstaande code maakt een kleine dataset van drie bekende UFC-vechters en toont deze als tabel:

Code


import pandas as pd

data = {
    'Fighter': ['Jon Jones', 'Francis Ngannou', 'Stipe Miocic'],
    'Age': [35, 36, 40],
    'Reach (inches)': [84.5, 83, 80],
    'Wins': [27, 17, 20]
}

df = pd.DataFrame(data)
df

Tabel

Fighter Age Reach (inches) Wins
Jon Jones 35 84.5 27
Francis Ngannou 36 83 17
Stipe Miocic 40 80 20

Deze tabel toont enkele kernstatistieken van bekende UFC-vechters in de heavyweight-divisie.
